# Data Loss Prevention

Fonte: Postman API Reference Library, espaço "Atlassian (Cloud)" (lido em 28/09/2026). 8 funções.


## Classification Level

| Método | Caminho | Função |
|---|---|---|
| POST | `orgs/:orgId/classification-levels` | Create a new classification level |
| GET | `orgs/:orgId/classification-levels` | Get all classification levels by orgId |
| GET | `orgs/:orgId/classification-levels/:levelId` | Get a classification level |
| PUT | `orgs/:orgId/classification-levels/:levelId` | Edit a classification level |
| POST | `orgs/:orgId/classification-levels/publish` | Publish classification level(s) |
| POST | `orgs/:orgId/classification-levels/archive` | Archive a data classification level |
| POST | `orgs/:orgId/classification-levels/restore` | Restore a classification level |
| POST | `orgs/:orgId/classification-levels/reorder` | Reorder classification levels |
