# E-mails do login (Supabase + Resend)

Colar cada arquivo em Supabase, Authentication, Emails (Templates), no modelo indicado. O assunto vai no campo Subject.

| Arquivo | Modelo no Supabase | Assunto |
|---|---|---|
| `recuperar-senha.html` | Reset Password | Crie uma senha nova para o CicloDev |
| `convite.html` | Invite user | Seu acesso ao CicloDev |
| `confirmar-email.html` | Confirm signup | Confirme o seu e-mail no CicloDev |
| `trocar-email.html` | Change Email Address | Confirme o e-mail novo no CicloDev |
