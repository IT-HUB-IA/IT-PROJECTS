# Site da IT.IA

Site institucional da IT.IA (it-ia.tec.br). Next.js, React, TypeScript, Tailwind e Framer Motion.

- Conteúdo: `data/site.ts`. Para lançar um produto novo, acrescente um item em `produtos` (ele ganha o próximo número de série) e tire o número de `naLinha`.
- Seções: `components/sections/`. Topo e rodapé: `components/layout/`.
- Cores, fontes e espaçamentos: tokens no começo de `app/globals.css` (tirados do logo da IT.IA).

Rodar local: `npm install` e `npm run dev`. Conferir antes de subir: `npm run lint` e `npm run build`.
